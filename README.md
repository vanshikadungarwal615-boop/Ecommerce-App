# E-Commerce Application

A full-stack e-commerce application developed using MERN stack.

## Features

### User
- User Registration
- User Login
- JWT Authentication
- Browse Products
- Add Products to Cart
- Place Orders
- View Order History

### Admin
- Admin Dashboard
- Add Products
- Update Products
- Delete Products
- View All Orders
- Update Order Status

## Technologies Used


Frontend:
- React.js
- Vite
- Bootstrap

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT

## Project Structure

client - Frontend  
server - Backend
